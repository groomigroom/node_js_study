fetch()
서버와 네트워크 요청을 보내고 응답을 받아오는 비동기 통신 함수입니다.
주로 웹페이지를 새로고침하지 않고 서버에서 JSON 같은 데이터를 가져올 때 사용합니다.
핵심 특징
비동기 처리: 코드가 멈추지 않고 백그라운드에서 서버와 통신하며, 
결과는 Promise 객체로 반환됩니다.
간편한 사용: 과거에 쓰이던 복잡한 XMLHttpRequest를 대신해 직관적이고 다루기 쉽게 만들어졌습니다.
기본 문법: 첫 번째 인자로 요청할 URL, 두 번째 인자로 선택적 옵션 객체(Method, Headers 등)를 받습니다.
주요 활용 방법
데이터 조회 (GET): 서버에 저장된 정보를 가져옵니다.javascript
fetch('https://example.com')
  .then(response => response.json())
  .then(data => console.log(data));
코드를 사용할 때는 주의가 필요합니다.데이터 전송 (POST 등): 서버로 새로운 정보를 보낼 때 옵션을 지정합니다.
javascript
fetch('https://example.com', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: '홍길동' })
});
