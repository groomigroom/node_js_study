React TSX(그리고 자바스크립트/타이프스크립트)에서 점 세 개(...)는 나머지 매개변수(Rest) 
또는 전개 구문(Spread)을 뜻합니다. 

전개 구문 (Spread Syntax)객체나 배열 안의 값들을 펼쳐서 다른 객체나 배열, 
또는 함수의 인자로 전달할 때 씁니다.
Props 전달하기: <MyComponent {...props} /> 처럼 쓰면 객체 안의 모든 속성을 컴포넌트의 props로 한 번에 넘깁니다.

객체/배열 복사 및 수정: const newObj = { ...oldObj, name: 'kim' } 처럼 기존 값을 복사하면서 특정 값만 바꿀 때 씁니다.
나머지 매개변수 (Rest Parameter)함수나 컴포넌트가 남은 모든 인자나 속성을 하나의 배열 또는 객체로 모을 때 씁니다.
Rest Props: function MyComponent({ title, ...rest }) 처럼 쓰면 title을 뺀 나머지 속성들이 rest 객체로 묶입니다.
Rest Parameter: function sum(...args: number[]) 처럼 전달된 여러 개의 인자를 하나의 배열(args)로 받습니다.
