Node.js에서 HTML <form>으로 전송한 데이터를 받을 때 req.body는 HTTP 요청의 본문(body)에 담겨서 전송된 폼 데이터를 객체 형태로 가지고 있는 값입니다.

예를 들어:

1. HTML에서 form 전송

<form action="/login" method="post">
    <input type="text" name="username">
    <input type="password" name="password">

    <button type="submit">로그인</button>
</form>

사용자가

username = hong
password = 1234

를 입력하고 제출하면 브라우저가 대략 다음과 같은 요청을 보냅니다.

POST /login

username=hong&password=1234

여기서 username, password가 HTTP request body에 들어갑니다.


---

2. Express에서 req.body로 받기

Node.js에서 Express를 사용한다면:

const express = require("express");

const app = express();

app.use(express.urlencoded({ extended: true }));

app.post("/login", (req, res) => {
    console.log(req.body);
});

그러면:

req.body

에는

{
    username: "hong",
    password: "1234"
}

가 들어옵니다.

따라서 각각 접근하려면:

req.body.username
req.body.password

이렇게 하면 됩니다.


---

3. 왜 req.body인가?

HTTP 요청은 크게 생각하면 다음과 같은 구조입니다.

Request
 ├─ URL
 ├─ Method
 ├─ Headers
 └─ Body
       ├─ username=hong
       └─ password=1234

Node.js/Express에서는 이 Body 부분을 req.body로 접근하는 것입니다.

즉,

req

→ 클라이언트가 서버로 보낸 전체 요청

req.body

→ 그 요청의 본문 데이터

req.body.username

→ 본문에 들어온 username 값

이라고 이해하면 됩니다.


---

4. name이 중요합니다

HTML에서:

<input type="text" name="username">

name="username"이 있어야 Express에서:

req.body.username

으로 받을 수 있습니다.

예를 들어:

<input type="text" name="id">
<input type="password" name="pw">

라면:

console.log(req.body);

결과는:

{
    id: "입력한 아이디",
    pw: "입력한 비밀번호"
}

입니다.

즉 input의 value가 name을 key로 하여 req.body에 들어간다고 생각하면 이해하기 쉽습니다.

<input name="username" value="hong">

             ↓ form 제출

req.body

{
    username: "hong"
}

그리고 req.body가 실제로 동작하려면 express.urlencoded() 같은 body parser 미들웨어가 필요합니다.
