Node.js에서 GraphQL을 사용하는 가장 표준적인 방법은 Apollo Server 라이브러리를 활용하는 것입니다. GraphQL 서버는 데이터의 구조를 정의하는 Schema(TypeDefs)와 데이터를 실제로 가져오는 로직인 Resolver의 조합으로 구성됩니다. [1, 2] 
가장 빠르게 시작할 수 있는 최신 기준 코드(Apollo Server v4 + Express) 예시입니다.
------------------------------
## 1. 프로젝트 설정 및 라이브러리 설치
새 폴더를 만들고 Node.js 프로젝트를 초기화한 뒤 필수 패키지를 설치합니다. [2, 3] 

mkdir graphql-demo
cd graphql-demo
npm init -y
npm install @apollo/server graphql cors body-parser

Tip: 최신 JavaScript 문법(import/export)을 사용하기 위해 package.json 파일에 "type": "module"을 추가해 주세요.

------------------------------
## 2. 기본 코드 작성 (index.js)
서버 폴더에 index.js 파일을 만들고 아래 코드를 작성합니다.

import { ApolloServer } from '@apollo/server';import { startStandaloneServer } from '@apollo/server/standalone';
// 1. 데이터 샘플 (데이터베이스 대신 사용)const books = [
  { title: 'The Awakening', author: 'Kate Chopin' },
  { title: 'City of Glass', author: 'Paul Auster' },
];
// 2. GraphQL 스키마 정의 (Type Definitions)// 클라이언트가 어떤 데이터를 요청할 수 있는지 계약을 정의합니다.const typeDefs = `#graphql
  type Book {
    title: String
    author: String
  }

  type Query {
    books: [Book]
  }
`;
// 3. 리졸버 정의 (Resolvers)// 스키마에 정의된 쿼리가 호출되었을 때 실제로 데이터를 반환하는 함수입니다.const resolvers = {
  Query: {
    books: () => books,
  },
};
// 4. 아폴로 서버 인스턴스 생성const server = new ApolloServer({
  typeDefs,
  resolvers,
});
// 5. 서버 시작 (기본 포트: 4000)const { url } = await startStandaloneServer(server, {
  listen: { port: 4000 },
});

console.log(`🚀 서버 준비 완료: ${url}`);

------------------------------
## 3. 서버 실행 및 테스트
터미널에서 서버를 실행합니다.

node index.js

서버가 켜지면 브라우저를 열고 http://localhost:4000에 접속합니다. GraphQL 웹 테스트 도구인 Apollo Sandbox가 열립니다.
## 쿼리(Query) 날려보기
왼쪽 창에 아래 쿼리를 입력하고 실행 버튼을 누르면 원하는 데이터만 정확하게 받아오는 것을 확인할 수 있습니다. [4, 5] 

query {
  books {
    title
  }
}

------------------------------
## 💡 핵심 개념 3가지 요약

* 
* Schema (typeDefs): API의 구조를 정의합니다. 무엇을 요청할 수 있고 어떤 타입(String, Int, Boolean 등)이 반환되는지 지정합니다.
* Query & Mutation: 데이터를 조회할 때는 Query를 사용하고, 생성·수정·삭제할 때는 Mutation을 사용합니다.
* Resolvers: 데이터를 반환하는 실제 비즈니스 로직입니다. 이 안에서 DB(MySQL, MongoDB 등)나 외부 REST API를 호출하여 데이터를 가져옵니다. [1, 2, 6, 7, 8]
