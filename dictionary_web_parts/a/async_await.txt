자바스크립트에서 async와 await는 비동기(Asynchronous) 작업을 쉽게 처리하기 위한 문법입니다.

특히 Node.js에서 서버를 만들 때 아주 자주 사용합니다.

1. async란?

함수 앞에 async를 붙이면 그 함수는 비동기 함수가 되고, 항상 Promise를 반환합니다.

async function hello() {
    return "Hello";
}

이 함수의 결과는 단순히 "Hello"가 아니라:

Promise

입니다.

그래서:

hello().then(result => {
    console.log(result);
});

실행하면:

Hello

가 출력됩니다.


---

2. await란?

await는 Promise가 처리될 때까지 기다렸다가 결과를 받는 것입니다.

async function hello() {
    const result = await Promise.resolve("Hello");

    console.log(result);
}

여기서

await Promise.resolve("Hello")

는 "Hello"라는 결과가 나올 때까지 기다린 다음 result에 넣습니다.

즉,

const result = await Promise.resolve("Hello");

를 개념적으로 보면:

> "이 비동기 작업이 끝날 때까지 여기서 잠시 기다리고, 끝나면 결과를 result에 넣어줘."



라고 이해하면 됩니다.


---

3. async와 await는 같이 사용

보통 다음과 같이 사용합니다.

async function getUser() {
    const response = await fetch("/api/user");
    const data = await response.json();

    console.log(data);
}

순서를 보면:

getUser()
   ↓
fetch("/api/user")
   ↓
서버의 응답을 기다림
   ↓
response
   ↓
response.json() 실행
   ↓
JSON 변환이 끝나기를 기다림
   ↓
data

await가 있기 때문에 코드가 위에서 아래로 순서대로 실행되는 것처럼 작성할 수 있습니다.


---

4. await가 없으면?

예를 들어:

async function getUser() {
    const response = fetch("/api/user");

    console.log(response);
}

여기서 response에는 실제 사용자 데이터가 아니라 Promise 객체가 들어갑니다.

반면:

async function getUser() {
    const response = await fetch("/api/user");

    console.log(response);
}

라고 하면 fetch()가 완료된 후 response에 실제 응답 객체가 들어갑니다.


---

5. 중요한 점

await는 아무 곳에서나 사용할 수 있는 것은 아닙니다.

일반적인 함수에서는:

function getUser() {
    const response = await fetch("/api/user");
}

❌ 오류가 발생합니다.

await를 사용하려면 보통:

async function getUser() {
    const response = await fetch("/api/user");
}

처럼 async 함수 안에서 사용합니다.


---

6. Node.js에서 보면 더 이해하기 쉽습니다

예를 들어 DB에서 사용자를 가져오는 코드가 있다고 하면:

app.get("/user", async (req, res) => {
    const user = await getUserFromDatabase();

    res.json(user);
});

여기서:

async (req, res) => {

→ 이 라우트 함수가 비동기 함수라는 의미

그리고:

const user = await getUserFromDatabase();

→ DB 작업이 끝날 때까지 기다린 후 결과를 user에 넣는다는 의미입니다.


---

한 줄로 정리

async = "이 함수는 비동기 작업을 처리하는 함수야."

await = "Promise 작업이 끝날 때까지 기다렸다가 결과를 받아와."

따라서 Node.js에서는 보통

async function 함수() {
    const 결과 = await 비동기작업();
}

형태로 사용한다고 기억하면 됩니다.
