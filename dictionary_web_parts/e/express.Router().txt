Node.js [Express](https://expressjs.com/)에서 express.Router()는 특정 엔드포인트(URL 경로)들을 별도의 파일로 분리하여 관리할 수 있게 해주는 '미니 애플리케이션(Mini-app)'입니다. 메인 서버 파일(app.js 또는 index.js)에 모든 API 경로를 작성하면 코드가 길어지고 복잡해지기 때문에, 관련 있는 경로끼리 묶어 모듈화할 때 사용합니다. [1, 2] 
이해를 돕기 위해 기존 방식과 express.Router()를 사용한 방식을 비교해 드릴게요.
## ❌ express.Router()를 사용하지 않을 때 (모든 코드가 한 파일에 집중)
앱이 커질수록 메인 파일이 수천 줄로 늘어나 가독성이 떨어집니다. [2, 3] 

// app.js (메인 파일)const express = require('express');const app = express();
// 유저 관련 기능
app.get('/users/profile', (req, res) => { res.send('유저 프로필'); });
app.post('/users/signup', (req, res) => { res.send('회원가입'); });
// 상품 관련 기능
app.get('/products/list', (req, res) => { res.send('상품 목록'); });
app.get('/products/detail', (req, res) => { res.send('상품 상세'); });

app.listen(3000);

------------------------------
## express.Router()를 사용할 때 (기능별 파일 분리)
기능에 따라 파일을 쪼개어 관리할 수 있어 유지보수가 매우 쉬워집니다. [2] 
1. 유저 전용 라우터 파일 생성

// routes/user.jsconst express = require('express');const router = express.Router(); // 1. 라우터 인스턴스 생성
// app.get 대신 router.get을 사용합니다.// 메인 파일에서 공통 경로(/users)를 지정해줄 것이므로 여기서는 생략합니다.
router.get('/profile', (req, res) => { res.send('유저 프로필'); });
router.post('/signup', (req, res) => { res.send('회원가입'); });

module.exports = router; // 2. 라우터를 모듈로 내보내기

2. 메인 파일에서 연결

// app.js (메인 파일)const express = require('express');const app = express();
const userRouter = require('./routes/user'); // 1. 라우터 파일 불러오기
// 2. "/users"로 시작하는 모든 요청은 userRouter가 처리하도록 연결 (마운트)
app.use('/users', userRouter); 

app.listen(3000);

------------------------------
## 핵심 장점 3가지

* 
* 코드 가독성 향상: 메인 파일의 복잡도를 낮추고 도메인(유저, 상품, 게시판 등)별로 코드를 격리합니다.
* 중복 경로 제거: 메인 파일에서 app.use('/users', ...)와 같이 공통 접두사를 한 번만 정의하면 라우터 내부에서는 하위 경로만 작성하면 됩니다.
* 라우터 전용 미들웨어: 특정 그룹의 API에만 로그인 인증 같은 [미들웨어](https://expressjs.com/ko/guide/using-middleware.html)를 따로 적용하기 편리합니다. [2, 3] 
* 

혹시 현재 만드시는 프로젝트에 라우터를 실제로 도입하다가 막히는 부분이 있거나, 폴더 구조를 어떻게 짜야 할지 고민이신가요? 상황을 공유해주시면 알맞은 폴더 구조 예시를 추천해 드릴게요!
